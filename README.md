# CATCHU(Achados e Perdidos) 🚀

Aplicação web full stack desenvolvida como Trabalho de Conclusão de Curso (TCC) do Ensino Médio Técnico, com foco em experiência do usuário, integração com API REST e gerenciamento de banco de dados.

---

## 📚 Sobre o projeto

O projeto foi desenvolvido em equipe por 4 integrantes com o objetivo de criar uma plataforma web completa, utilizando tecnologias modernas de front-end, back-end e banco de dados.

A aplicação conta com:
- interface responsiva
- integração com API
- gerenciamento de dados
- autenticação
- comunicação entre front-end e back-end

## ⚙️ Como executar o projeto

### Clonar os repositórios

```bash
git clone https://github.com/Grinaldi20/3etim-tcc-catchu.git
git clone https://github.com/Grinaldi20/api-node-catchu.git
```

---

### Configurar o Front-end

```bash
cd frontend

npm install

npm run dev
```
